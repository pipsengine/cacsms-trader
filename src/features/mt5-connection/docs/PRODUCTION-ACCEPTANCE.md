# Production Acceptance

## Connection & authentication

Connection & authentication is implemented as an explicit integration concern rather than a visual-only field. The production adapter must source authoritative values from the connected MT5 account, broker contract specification, Cacsms risk engine, or versioned prop-firm profile as applicable. State changes must be timestamped, attributable, and observable from the MT5 Connection module. A missing, stale, contradictory, or unavailable required value must never silently become permission to trade.

Acceptance checks include successful state, degraded state, disconnect/reconnect, stale data, invalid configuration, account isolation, and audit evidence. UI controls must reflect adapter capabilities and remain disabled when the backend capability is unavailable.
